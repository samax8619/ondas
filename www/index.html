¿Por qué un navegador no puede medir dBm?

Ninguna API web (ni en Chrome, ni en Safari, ni en Firefox) expone la potencia recibida (RSRP/RSSI) ni la frecuencia del módem celular. El navegador solo ve la red como “un enlace con cierta latencia y velocidad estimadas”.

Para leer dBm y canal hace falta una app nativa. Esta interfaz está hecha para funcionar dentro de un contenedor Capacitor en Android, donde un plugin lee TelephonyManager y envía los datos a esta misma pantalla. Los detalles están en el README.
